# paper-spec —— 卷型结构规格（题号 / 分值 / 时长）

**这份文档回答**：我们要支持的两套卷型，各部分叫什么、题号从哪到哪、每题几分、总共多少分；
以及 skill 用它做**覆盖率自检**（题号是否连续、分值是否凑够 150）。

**读者**：写 `scripts/validate.py`、`references/tags.md` 和模板的人。
**核实状态**：结构均有来源或真题答案佐证；个别数字标注「待核实」，**不要当成事实使用**。

## 1. 适用范围（2026 年视角）

| 卷型 | 状态 | 说明 |
|---|---|---|
| 新高考全国卷（新课标 Ⅰ 卷 / Ⅱ 卷） | **当前在用** | 含读后续写、无短文改错；完形 15 题 |
| 老全国卷（全国甲卷 / 全国乙卷） | **2025 年及以前使用，已停用** | 含短文改错、完形 20 题；做历年真题/教辅仍会大量遇到，**必须兼容** |

## 2. 新高考全国卷（新课标 Ⅰ/Ⅱ 卷）— 150 分 / 120 分钟

| 部分 | 节 | 题型 | 题号 | 题量 | 每题分 | 小计 |
|---|---|---|---|---:|---:|---:|
| 第一部分 听力 | 第一节 | 听 5 段对话，每段 1 题 | 1–5 | 5 | 1.5 | 7.5 |
| | 第二节 | 听 5 段对话/独白，每段多题 | 6–20 | 15 | 1.5 | 22.5 |
| | | **听力小计** | **1–20** | **20** | | **30** |
| 第二部分 阅读理解 | 第一节 | 短文阅读（A 篇 3 题，B/C/D 各 4 题） | 21–35 | 15 | 2.5 | 37.5 |
| | 第二节 | 七选五（5 空，选项 A–G） | 36–40 | 5 | 2.5 | 12.5 |
| | | **阅读小计** | **21–40** | **20** | | **50** |
| 第三部分 语言知识运用 | 第一节 | 完形填空（4 选 1） | 41–55 | 15 | 1 | 15 |
| | 第二节 | 语法填空（10 空，含提示词/纯空格） | 56–65 | 10 | 1.5 | 15 |
| | | **语言运用小计** | **41–65** | **25** | | **30** |
| 第四部分 写作 | 第一节 | 应用文写作（约 80 词） | 无题号 | 1 | 15 | 15 |
| | 第二节 | 读后续写（约 150 词，含两段首句） | 无题号 | 1 | 25 | 25 |
| | | **写作小计** | | **2** | | **40** |
| | | **全卷合计** | **1–65 + 2 篇写作** | **67 题** | | **150** |

**校验公式**：`30 + 50 + 30 + 40 = 150`；客观题号连续区间为 **1–65**。

## 3. 老全国卷（全国甲卷 / 乙卷）— 150 分 / 120 分钟

| 部分 | 节 | 题型 | 题号 | 题量 | 每题分 | 小计 |
|---|---|---|---|---|---|---:|
| 第一部分 听力 | 第一/二节 | 同新高考卷 | 1–20 | 20 | 1.5 | 30 |
| 第二部分 阅读理解 | 第一节 | 短文阅读（A 篇 3 题，B/C/D 各 4 题） | 21–35 | 15 | 2 | 30 |
| | 第二节 | 七选五 | 36–40 | 5 | 2 | 10 |
| | | **阅读小计** | **21–40** | **20** | | **40** |
| 第三部分 语言知识运用 | 第一节 | 完形填空 | 41–60 | **20** | 1.5 | **30** |
| | 第二节 | 语法填空 | 61–70 | 10 | 1.5 | 15 |
| | | **小计** | **41–70** | **30** | | **45** |
| 第四部分 写作 | 第一节 | **短文改错**（10 处错误，每处 1 分） | 无题号 | 10 处 | 1 | 10 |
| | 第二节 | 书面表达（约 100 词，应用文/提纲作文） | 无题号 | 1 | 25 | 25 |
| | | **写作小计** | | | | **35** |
| | | **全卷合计** | **1–70 + 改错 + 作文** | **72 题** | | **150** |

**校验公式**：`30 + 40 + 45 + 35 = 150`；客观题号连续区间为 **1–70**。

**真题佐证（2023 全国乙卷，答案结构实测）**：
阅读理解 `A: CAD`（3 题）`B: BACB`(4) `C: ADDB`(4) `D: ADBC`(4) → 15 题；七选五 `BDCEG` → 5 题；
完形填空答案 20 个 → **20 题**；语法填空答案标号 **61–70** → 10 题；另有短文改错与书面表达（原文标注"满分 25 分"）。
使用省份原文标注：河南、江西、甘肃、陕西、宁夏、新疆、青海、内蒙古。
来源：<https://www.meipian.cn/4si0vggw>（转载的真题答案页）。

## 4. 两套卷型差异对照（skill 必须按卷型分支的地方）

| 维度 | 新高考卷（新课标Ⅰ/Ⅱ） | 老全国卷（甲/乙） |
|---|---|---|
| 阅读每题分值 | **2.5 分**（15 题 = 37.5） | **2 分**（15 题 = 30） |
| 七选五每题分值 | 2.5 分（12.5） | 2 分（10） |
| 阅读总分 | **50** | **40** |
| 完形填空 | **15 题**（41–55），每题 **1** 分，共 15 | **20 题**（41–60），每题 **1.5** 分，共 30 |
| 语法填空题号 | **56–65** | **61–70** |
| 客观题号上限 | **65** | **70** |
| 写作第一节 | **应用文写作 15 分** | **短文改错 10 分** |
| 写作第二节 | **读后续写 25 分** | 书面表达 25 分 |
| 写作总分 | **40** | **35** |
| 语言运用总分 | 30 | 45 |

> 一句话记法：**老卷"阅读便宜、完形贵、多一个短文改错"；新卷"阅读涨价、完形减半、改成读后续写"。**

## 6. 评分档次骨架（写作 rubric 用，**需按当年官方细则校准**）

| 题型 | 满分 | 档次（分） |
|---|---:|---|
| 应用文写作（新高考） | 15 | 13–15 / 10–12 / 7–9 / 4–6 / 1–3 |
| 读后续写（新高考） | 25 | 21–25 / 16–20 / 11–15 / 6–10 / 1–5 |
| 书面表达（老全国卷） | 25 | 21–25 / 16–20 / 11–15 / 6–10 / 1–5 |

## 7. 时长与建议用时（教学建议值，非官方）

全卷 **120 分钟**（含听力，听力约 20 分钟）。

| 部分 | 建议用时 | 说明 |
|---|---:|---|
| 听力 | 20′ | 随录音走，不可压缩 |
| 阅读理解（含七选五） | 35′ | 平均每篇 7–8′ |
| 语言知识运用（完形+语法填空） | 25′ | 完形 15′、语法填空 10′ |
| 写作（应用文 + 读后续写） | 40′ | 应用文 15′、读后续写 25′ |

## 8. 变体与坑（写进 skill 的注意事项）

1. **听力计分差异**：少数省份听力不计入总分或单独考两次（如浙江有听力单独考试），遇到时以试卷标注为准，不要硬按 30 分算。
2. **老卷 2024 版存疑**：有第三方文章称 2024 全国甲卷"阅读理解 15 小题满分 37.5 分"（即 2.5 分/题），
   但**同一篇文章还把"读后续写"写进了甲卷分析**，明显是拼凑内容，**可信度低**。
   → 处理 2024 甲卷前**必须用真题原卷复核**；默认按本文 §3 的老卷结构处理，并在报告里标注不确定。
3. **省份映射随年份变动**（2026 起甲/乙卷停用，原甲卷省份转新课标Ⅱ卷、原乙卷省份转新课标Ⅰ/Ⅱ卷），
   不要把它写死进数据，只作为 `meta.paper` 的可选值。
4. **题号从 1 开始连续**是两套卷型的共同特征（写作部分无题号）——这是覆盖率自检的基础。
5. 部分省份使用**独立听力试题**或调整听力播放次数，属地方差异，暂不在支持范围。

## 9. skill 落地要点

- JSON 的 `meta.paper` 取值：`新课标I卷` / `新课标II卷` / `全国甲卷` / `全国乙卷`（可扩展）。
- `meta.section` 用本文的"部分/节"名称，便于总览页聚合。
- `references/validate` 规则：
  1. 题号必须覆盖 `1..65`（新高考）或 `1..70`（老卷），无缺号、无重复；
  2. 各部分分值之和必须 = 150；
  3. 老卷必须能找到 `correction`（短文改错），新高考必须能找到 `writing-cont`（读后续写）；
  4. 题型缺失时报告为"该卷型应含但未解析到"，而不是静默跳过。
