# 考点标签库（`points[].tag` 怎么写）

> 用途：掌握度按标签聚合（"细节理解/转折句概括 3 对 4 错"），所以标签必须**可复用**，不能每题现编。
> 写法：`一级能力/二级考点`，中间用**半角斜杠**，不要用 `·`、不要用空格、不要中英混排。

## 一级能力（只有 7 个，别新造）

| 一级 | 用在哪些题型 | 一句话 |
|---|---|---|
| `细节理解` | 阅读 | 答案在原文能指到具体句子 |
| `推理判断` | 阅读 | 原文没直说，要靠因果/评价/人物行为推出来 |
| `主旨大意` | 阅读 | 段落主旨、标题、写作目的 |
| `词义猜测` | 阅读 | 猜词/猜短语/猜指代 |
| `语篇衔接` | 七选五 | 空格的"接口"性质：标题位、段首位、例证位、指代链 |
| `词汇` | 完形 | 语境里的词义、搭配、复现 |
| `语法` | 语法填空 | 语法点本身 |

## 二级考点（推荐取值，够用就别加）

### 细节理解
| 二级 | 什么时候用 | 真实例子 |
|---|---|---|
| `目的句定位` | 问 main purpose / why 某机构设立 | `细节理解/目的句定位` |
| `数字与否定` | 需要分辨数字、hardly/not/only 这类 | `细节理解/数字与否定` |
| `正反判断` | 问"哪项被允许/哪项不符合"（permitted / not encouraged） | `细节理解/正反判断` |
| `转折句概括` | 答案句带 But / However | `细节理解/转折句概括` |
| `引语言外之意` | 答案要理解直接引语的含义 | `细节理解/引语言外之意` |

### 推理判断
| 二级 | 说明 |
|---|---|
| `因果推断` | 由结果推原因，或由原因推结果 |
| `评价句推断` | 依据评价性形容词/副词（positive / surprisingly） |
| `人物性格/全文整合` | 要多段互证才能得出人物品质 |

### 主旨大意
`段落主旨` / `标题选择` / `写作目的`

### 词义猜测
`上下文线索`（同义复现、反义对照）/ `构词法`

### 语篇衔接（七选五）
| 二级 | 判别问句 |
|---|---|
| `小标题概括` | 这一段是不是"分点式"？空是不是在段首独占一行？ |
| `段首接题` | 空在段首、要引出整段内容 |
| `同指词链` | 空格前后有没有 this / these / such / the + 名词 指回前文 |
| `举例呼应` | 后文是不是 For example / such as |
| `指代与逻辑后果` | 前文说 A，空里要说 A 导致的结果 |
| `承接收束` | 空在段末，要收束本段 |

### 词汇（完形）
`名词辨析` / `动词辨析` / `形容词辨析` / `副词辨析` / `动词短语` / `固定搭配` / `语义复现` / `逻辑关系-转折` / `逻辑关系-因果` / `逻辑关系-结果`

> 辨析类后面可再跟一个语境提示，例如 `词汇/动词辨析(语境)`——但括号只允许出现在二级末尾，不要再套第三级。

### 语法（语法填空）
`时态语态-一般过去时` / `时态语态-一般过去时的被动` / `非谓语-不定式作目的状语` / `非谓语-过去分词作定语` / `非谓语-过去分词(状语从句省略)` / `定语从句-关系代词作主语` / `定语从句-关系副词` / `名词性从句-宾语从句` / `状语从句-让步` / `状语从句-时间` / `代词-反身代词` / `冠词-定冠词` / `冠词-不定冠词` / `介词-固定搭配` / `比较级` / `词性转换-名词变形容词` / `词性转换-形容词变副词` / `主谓一致`

## 好/坏例子

| ✅ 好 | ❌ 坏 | 为什么 |
|---|---|---|
| `细节理解/转折句概括` | `细节题 · 转折句概括` | 用了 `·`，聚合键会被拆成两种 |
| `语法/非谓语-过去分词作定语` | `非谓语动词 · 过去分词作定语` | 没有一级能力，以后无法按"语法"整体统计 |
| `词汇/动词短语辨析` | `动词短语/搭配` | 一级缺失；`/搭配` 又与 `固定搭配` 重名 |
| `语篇衔接/同指词链` | `七选五/同指词链` | `七选五` 是题型不是能力；换成题型后同一考点无法跨题型复用 |

## 迁移旧数据（可选，一次性）

老样例里的一批标签可以照下表映射；**不要批量改历史数据**，新数据按本规范写即可：

| 旧 | 新 |
|---|---|
| `细节题 · …` | `细节理解/…` |
| `推断题 · …` | `推理判断/…` |
| `七选五/…` | `语篇衔接/…` |
| `固定搭配 …` / `动词短语/搭配` | `词汇/固定搭配` / `词汇/动词短语` |
| `非谓语动词 · …` / `定语从句 · …` / `时态 · …` | `语法/…`（保留后半段，`·` 换成 `-`） |
